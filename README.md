# 💳 AI UPI Fraud Detection Dashboard

An AI-powered UPI Fraud Detection and Analytics Dashboard built using **Machine Learning**, **Streamlit**, **Python**, and **Plotly**.

This project analyzes UPI transaction behavior, detects suspicious transactions, and visualizes fraud analytics through an interactive dashboard.

---

# 🚀 Features

✅ Fraud Detection using Machine Learning
✅ Interactive Streamlit Web App
✅ Real-time Fraud Risk Prediction
✅ Risk Score Gauge Meter
✅ UPI Transaction Analytics Dashboard
✅ Category-wise Fraud Analysis
✅ Fraud Trend Visualization
✅ Attractive Fintech UI with Animations
✅ KPI Cards and Charts

---

# ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/V16-vishu/ai-upi-fraud-detection-system.git
```

Go to project folder:

```bash
cd ai-upi-fraud-detection-system
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

# ▶️ Run the Application

```bash
streamlit run app/streamlit_app.py
```
